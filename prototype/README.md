# 数信 IM 演示原型

在浏览器打开 index.html。默认已填好示例手机号 13800000000、密码 demo1234 和示例验证码，点「登录」进入聊天。刷新验证码后按页面所示填写。注册或修改密码后，使用当前演示会话中的账号和密码。刷新页面会恢复初始数据。

## 演示路径

1. **注册。** 填写示例手机号 13800000001、任意示例昵称和邀请码，输入两次相同的示例密码及当前图形验证码。可以选择本地头像、查看协议和隐私政策。勾选协议后提交示例注册，完成后返回登录。
2. **聊天。** 按全部、联系人或群组查看会话。长按会话并点「选择聊天」可批量标记已读。打开「林晓」发送一条消息，返回后查看摘要。长按或右键点击文本消息可打开操作菜单，也可聚焦后按 Shift+F10。在「产品协作群」试用红包，在聊天的加号面板可选取本地示例图片。点麦克风开始计时，向左滑动或点击取消键可结束本次录音演示，点发送会发出本地示例音频。
3. **联系人。** 搜索联系人并从资料页进入聊天。在「新的朋友」处理收到的申请。在添加好友页搜索「王婷」，发出申请后可看到「已发送」。
   在「联系人 → 新建群组」可填群名、选择公开或私密并选择成员。进入群聊后，点击群标题打开「群组信息」，查看公告、资料和成员。「设计评审群」或新建群可演示群主操作。其他示例群可演示普通成员退群确认。
4. **国家数据集团。** 播放 6 秒示例宣传片，打开新闻详情后返回。
5. **签到。** 点击「签到」，检查按钮状态、日历标记和「积分明细」。再次进入签到页可看到本次操作结果。
6. **我的。** 编辑资料或选取本地示例头像。可在钱包里使用示例账号 example@example.test 提交一笔模拟提现，查看状态和余额。在「会议」可用 820156321 加入示例会议，也可预约或立即创建。「通知 · 设备 · 网络」是同一页的三个标签。
7. **客服与发现。** 聊天页顶部的客服进入本地示例接待页。可直接打开 [发现](index.html#discover) 进入广场，选择可见范围并模拟提交审核。

原型在浏览器内使用本地示例数据。注册、会话、红包、补贴、钱包、会议、发布和密码操作均为模拟。新闻与宣传片是演示素材。「我的 → 签到」演示原 App 的全民补贴路径，底部「签到」演示需求文档中的商城积分活动。

用 `?subsidy=cycle#native-check` 可以从第 29 天继续签到，核对 30 天奖励、补贴明细和周期重置。用 `?subsidy=missed#native-check` 演示漏签后从第 1 天累计，保留已取得的补贴。

「我的」顶部可打开积分商城和幸运抽奖。列表中的「邀请好友」点击后直接复制当前原型的注册链接；「我的邀请码」保留复制邀请码、邀请统计和「我邀请的人」。要演示终止其他设备会话，使用 `?devices=multiple#settings` 后选择「设备」。

商城可按分类浏览实物，兑换前填写示例收货信息。兑换记录显示地址，可点开查看详情，之后也可从商品或积分消耗明细查看。幸运抽奖每个演示会话可抽一次，结果用弹窗展示，「抽奖记录」显示奖品和消耗。积分明细可按收支方向和积分类型筛选。

「产品协作群」有待领红包，拆开后可查看领取名单，再通过「我的钱包」中的「红包记录」入口查看收支明细。

在入口后加上 `?invite=optional&send=fail-once#register`，可展示邀请码选填，并在进入聊天后模拟首次发送失败。点击失败消息下方的重试可恢复。「邀请朋友」中的链接打开当前演示的注册页并预填示例邀请码。

在单聊的更多面板可体验示例语音或视频去电。在入口后加 `?call=incoming#messages`，打开第一个单聊时会收到一次示例来电。取消、拒绝或挂断后可查看聊天内的通话记录。

签到示例可通过入口参数打开。 `?check=missed&checkFail=once#check-in` 演示漏签和首次失败后重试，`?check=rollover#check-in` 演示跨月连续，`?check=empty#check-in` 演示补贴明细空状态，`?check=cycle#check-in` 演示连续奖励进度与样例发放结果。

「我的 → 设备」使用本地示例会话，可终止单台或所有其他设备。「修改密码」中登录密码的原始示例值是 demo1234。登录密码修改后，使用新示例密码重新登录。首次设置支付密码时使用任意六位示例数字即可。

在入口后加 `?withdraw=bank#wallet` 可演示服务端渠道配置的效果。选择示例银行卡时显示收款人、收款账号和开户银行，切回支付宝时仅显示其收款账号。可在提现方式页保存本地示例值，再从提现页选择该方式查看回填。

## APK 资源

Android APK 4.5.7 的提取资料保存于本地项目的 `apk-ui` 目录。`assets` 目录保存图二、V3 视觉素材和公开版使用的本地演示样例，包括独立生成的提示音。

Dart 页面和逻辑以编译产物随 APK 分发。此原型的 Vue 3 和 CSS 源文件位于本目录，正式 Android 改版需要原 Flutter 工程。
